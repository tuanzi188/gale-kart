# 疾风卡丁 · Gale Kart

单文件网页 3D 卡丁车游戏，包含竞速赛、道具赛和计时赛，重点优化手机横屏双拇指操作。

## 开始游玩

下载仓库后，使用支持 WebGL 的现代浏览器打开 index.html，也可以将仓库作为静态网站托管。无需安装项目依赖或执行构建。

游戏脚本和主要资源已内嵌。标题字体使用 Google Fonts，加载失败时回退到系统字体。

## 游戏内容

- 四条主题赛道：阳光小镇、黄金沙漠、冰雪乐园、霓虹夜城。
- 三种模式：竞速赛、道具赛、计时赛。
- 五种赛车、六位车手、多种涂装，可选择 AI 难度和圈数。
- 漂移集气、氮气、小喷、起步加速、加速带、跳台和多种道具。
- 本地成绩记录；三圈计时赛可保存最佳一局的幽灵车。

## 手机横屏操作

建议点击首页“全屏”，再将手机横过来。

| 动作 | 操作 |
| --- | --- |
| 加速 | 自动加速 |
| 转向 | 左拇指按住方向区，左右滑动切换，无需抬手 |
| 停止转向 | 松手或滑出方向区，保持按住滑回可继续 |
| 漂移 | 转向时右手按住“漂移”，结束后自动小喷 |
| 刹车与倒车 | 按住“刹车”；停稳后继续按可倒车 |
| 起步加速 | GO 出现时点“起步”，提前点击会失去奖励 |
| 氮气与道具 | 比赛中点击右侧“氮气”或“道具” |
| 交换道具 | 持有两件道具时点击“交换” |
| 复位 | 点击“复位”返回赛道 |
| 暂停与全屏 | 点击顶部暂停按钮，暂停页也提供全屏入口 |

方向区包含交界防抖和少量纵向容差。暂停、切后台或改变视口时会清理触控状态。

## 移动端优化

- 手机首次默认均衡画质，保留已有手动选择。
- 自动降档仅在触屏设备的实际比赛阶段采样。
- 预热约 3 秒后，连续两个约 2 秒窗口低于 42 帧且慢帧占比达标时，按精美 → 均衡 → 流畅降档。
- 每次降档后冷却约 8 秒，不自动升档；暂停和后台时间不计入。
- 渲染分辨率、阴影、泛光和粒子密度即时调整，地形及场景细节下一局更新。
- 竖屏开赛会暂停并提示横屏，也可选择继续竖屏。
- 支持的设备提供漂移、碰撞和道具短震动，设置中可关闭。
- 全屏和方向锁定取决于浏览器支持，不支持时可手动横屏游玩。
